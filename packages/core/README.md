# @heph/core

The single domain layer of Hephaestus (D7): database schema, migrations and every business rule. REST, MCP and the CLI are thin adapters over the `Domain` object; nothing else talks to the database.

| Path                                                                                                      | Contents                                                                                                                                                      |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/db/schema.ts`                                                                                        | Drizzle schema for the whole data model (§5). Timestamps are stored as UTC ISO text via `isoTime` (D39).                                                      |
| `drizzle/`                                                                                                | SQL migrations, generated by `npm run db:generate`. `0001_search_fts.sql` is hand-written (FTS5 + triggers). Never edit a migration after it is merged (D40). |
| `src/domain.ts`                                                                                           | `Domain`: wires the services; `tx()` runs a SQLite transaction.                                                                                               |
| `src/projects.ts`, `roadmap.ts`, `diary.ts`, `materials.ts`, `files.ts`, `proposals.ts`, `restructure.ts` | Services for each area of the spec.                                                                                                                           |
| `src/status.ts`, `sessions.ts`                                                                            | Computed activity, badge and dashboard order (§6, D25).                                                                                                       |
| `src/briefing.ts`, `format.ts`                                                                            | The agent briefing (§8) and shared Markdown helpers.                                                                                                          |
| `src/auth.ts`, `settings.ts`                                                                              | Single-user auth (D5), API token (D6), settings with defaults.                                                                                                |
| `src/search.ts`                                                                                           | FTS5 search with safe query building.                                                                                                                         |
| `src/test/`                                                                                               | Test helpers (`makeDomain()` with an in-memory DB and a controllable clock). Exposed as `@heph/core/testing`.                                                 |

Conventions:

- Every mutation takes a `Ctx` (who acts: `ui`, `claude_code`, `github`, `system`) and writes a `change_log` row.
- Inputs are validated with `@heph/schema`; failures throw `DomainError` with a code the adapters map to HTTP/MCP errors.
- Tests: `npx vitest run packages/core` (in-memory SQLite, invented data only).
