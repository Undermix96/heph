# Heph — pacchetto di design per l'implementazione

Interfaccia approvata di **Hephaestus (Heph)**, tema scuro.

1. Apri `index.html` nel browser: elenca tutte le 26 schermate (desktop, stati, telefono), collegate fra loro come un prototipo.
2. Leggi `DESIGN.md`: principi, componenti, regole di stato, comportamenti. **È il riferimento per l'implementazione.**
3. Usa `tokens.css` (o `tokens.json`) per tutti i colori, i caratteri, gli spazi e le misure.
4. `BRIEF.md` è il brief funzionale originale.

I mockup in `mockups/` sono HTML statico con stili inline e dati di esempio: copia la struttura e l'aspetto, non il codice.
Gli screenshot in `screenshots/` sono a 1440 px (desktop) e 390 px @2x (telefono).
